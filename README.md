# Khush Shah — Portfolio

A polished, responsive, zero-build portfolio for **Khush Shah**, focused on Data Science, Machine Learning, software engineering and problem solving.

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- No framework / no build step

## Run locally

Open `index.html` directly, or use VS Code Live Server.

## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload/push all files in this folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/root`.
6. Save.

Your portfolio will be available at:

`https://YOUR_USERNAME.github.io/REPOSITORY_NAME/`

## Deploy on Vercel

Import the GitHub repository into Vercel. No build command is required.

## Before publishing

Search `index.html` for:

- `YOUR_EMAIL@example.com`
- `YOUR_LINKEDIN`

Replace them with your real contact details.

Also update project GitHub/demo links when the repositories are public.

## Personalization

The portfolio intentionally avoids unsupported claims. Add actual awards, CGPA, certifications, rankings, competition results, internship details, resume link, and live project links only when you have the verified details.
